# Vestuário Pessoal

Sistema desenvolvido em Java para gerenciamento de peças de vestuário, permitindo organizar roupas, montar looks e acompanhar informações de uso, empréstimos e lavagens.

## Sobre o projeto

O projeto foi desenvolvido com foco em aprendizado e prática de conceitos de Programação Orientada a Objetos (POO), organização de sistemas em camadas e manipulação de dados.

A aplicação permite cadastrar diferentes tipos de peças de roupa, registrar usos e criar combinações de looks de forma organizada.

## Funcionalidades

* Cadastro de peças de vestuário

  * Parte de cima
  * Parte de baixo
  * Calçados
  * Acessórios
  * Peças íntimas

* Criação e gerenciamento de looks

* Registro de uso das roupas

* Controle de lavagem

* Controle de empréstimos

* Estatísticas de peças mais utilizadas

* Interface gráfica utilizando Java Swing

* Persistência de dados

## Tecnologias utilizadas

* Java
* Java Swing
* Programação Orientada a Objetos (POO)
* Git/GitHub
